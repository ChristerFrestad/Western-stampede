# ISO/IEC 27001 — ISMS Scope (Draft)

**Organization:** Western Stampede / game supplier RGS programme  
**Status:** Draft for Stage 1 preparation (not certified)

## 1. Scope statement

The Information Security Management System (ISMS) covers:

- Design, development, deployment, and operation of the **Western Stampede Remote Game Server (RGS)**
- **RNG core** (`@ws/rng-core`) and related audit artefacts
- Source code repositories, CI/CD, container images, and secrets used for the above
- Personnel and suppliers with access to production game logic, RNG, or player wallet interfaces

**Out of scope (initial):** Marketing websites, general office IT not touching gaming systems (to be reassessed).

## 2. Primary assets

| Asset | Classification |
| --- | --- |
| RNG source & design docs | Confidential / integrity-critical |
| Math configs & sim reports | Confidential / integrity-critical |
| Round / ledger / audit data | Confidential / regulatory |
| Admin tokens & JWT secrets | Secret |
| Operator wallet API keys | Secret |
| Public game client assets | Internal / public |

## 3. High-level risks (initial register)

| Risk | Impact | Treatment (tech) |
| --- | --- | --- |
| Weak / biased RNG | Regulatory, financial | CSPRNG + rejection + lab cert |
| Unauthorized math change | Fairness, licence | Version hash; mutation forbidden in compliance |
| Silent RNG fallback | Certification failure | Hard-fail external provider |
| Wallet double-spend | Financial | Idempotency + durable ledger |
| Secret leakage | Compromise | Env secrets; no secrets in git |
| Supply-chain malware | Integrity | Lockfile, SBOM, image scan (planned) |
